# Contributor Code of Conduct

## Our Pledge

AI INVESTOR OS is committed to providing an open, respectful and constructive environment for everyone participating in the project.

## Expected Behavior

All contributors are expected to:

- Be respectful and professional.
- Welcome different perspectives and experiences.
- Provide constructive feedback.
- Focus on what is best for the project.
- Respect other contributors and their work.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination.
- Personal attacks or insults.
- Publishing private information without consent.
- Deliberate disruption of project discussions.
- Any other inappropriate professional conduct.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions and other official project communication channels.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards.

Violations may result in warnings, removal of content or exclusion from project spaces.

## Contact

Report conduct concerns privately to the project maintainers through the repository's GitHub contact channels.
