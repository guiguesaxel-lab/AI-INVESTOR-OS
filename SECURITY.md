# Security Policy

## AI INVESTOR OS

Security is an important priority for AI INVESTOR OS.

As the project evolves, we aim to protect users, contributors, integrations and financial data.

## Supported Versions

Currently, AI INVESTOR OS is in the concept and architecture phase.

Security support will be defined as functional versions are released.

## Reporting a Vulnerability

If you discover a potential security vulnerability:

1. Do not publish sensitive details in a public GitHub issue.
2. Contact the project maintainers privately through GitHub.
3. Provide a clear description of the vulnerability.
4. Include reproduction steps when possible.

## Security Principles

The project intends to follow these principles:

- Never commit API keys, passwords or access tokens.
- Store credentials in environment variables.
- Validate external data sources.
- Apply least-privilege access.
- Protect user and portfolio data.
- Require explicit authorization for any future trading execution.
- Avoid exposing sensitive information in logs.

## Responsible Disclosure

We encourage responsible disclosure and will aim to investigate reported vulnerabilities promptly.

**AI INVESTOR OS — Security by design.**
